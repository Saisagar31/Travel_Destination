TROUBLESHOOTING:
----------------

Problem: No destinations showing
Solution: 
• Use destinations-fixed.html (not destinations.html)
• Clear browser cache (Ctrl+Shift+Delete)
• Hard refresh (Ctrl+F5)

Problem: Prices not in ₹
Solution:
• Check internet connection
• Wait a few seconds for conversion
• Check console (F12) for errors

Problem: Photos not loading
Solution:
• Check internet connection
• Wait for progressive loading
• Verify Pexels API quota

Problem: No attractions
Solution:
• This is normal for some locations
• OpenTripMap may have limited data
• Try different destinations
